# TripWhisper · 旅行工作台 v0.2

米兰＋科莫湖 3—5 天的中文旅行工作台。规则驱动原型，未接入真实大模型、实时天气、票务库存、支付或云端存储。

## 本轮新增

- **行程体检**：检查当前行程或粘贴 / 编辑文字计划；识别时间重叠、缓冲不足、锁定预订冲突和住宿缺失；每条有依据与修复建议，预览后确认才写入。失败或取消不覆盖原行程。
- **受约束重排**：在每日行动卡输入晚出门分钟和/或减少步行，先预览受影响项目、替代/移除、时间差与取舍，确认后才写入总行程、日卡和预算。锁定预订与交通时段不会被移动。
- **我的预订**：录入日期、起止时间、当地地址、每人价格与公开链接；含 15 分钟衔接检查。与已订项目或交通冲突时阻止加入，与普通活动冲突时先列出将移除的安排，确认后应用。支持从行程移除记录（不会取消真实订单）。
- **预订保留**：重新生成仍保留用户预订的绝对日期与时段；预订不在新日期范围或与新安排冲突时阻止生成。
- **旅行账本**：欧元/人民币金额、分类、日期、每日汇总、预算差额、删除撤销。金额以最小货币单位计算；人民币按录入时的手填汇率折算，不假装实时汇率。
- **背景手册**：出发准备清单、当前行程背景、交通与官网入口、意大利语常用表达；可打印当前章节。
- **每日行程图**：由同一份行程数据生成可下载 PNG，含时间、地址、交通、预订锁定状态；不是网页截图。
- **数据兼容**：保留已有本机行程与回顾，新增账本和准备清单随旅行备份一起导出。

## 已实现

偏好表单、城市概览、按偏好生成安排、每日行动卡、地图与官方入口、模拟预订锁定、行程体检与修复预览确认、结构化晚出门/少走路重排预览及确认、雨天室内替换、恢复上一版本、预算参考、文字回顾、偏好记忆复用、本机保存、JSON/文字导出、全程打印。

所有金额和交通时长是示范估值。固定预订为模拟约束。实际营业、班次和可用性需用户核实。住宿文本仅用于记录，不表示路线已按酒店地址计算。浏览器存储仅保存当前设备数据，不跨设备同步。

## 开发

Node >=22.13，npm install，npm run dev。npm run build 用于发布构建。npm run lint 和 npx tsc --noEmit 可检查代码。

规则回归：

```sh
node --experimental-strip-types tests/journey.test.mjs
node tests/workspace.test.mjs
node tests/replan.test.mjs
node tests/health.test.mjs
```

覆盖预订保留与重新生成、无原地修改、时间顺序、日期与金额合法性、锁定与交通冲突、缓冲时段、URL 协议校验、记忆与兴趣、精确小数、人民币换算、每日账本汇总，受约束重排的预览隔离、锁定/交通不可移动、顺延/压缩/移除与步行替换，以及行程体检的四类检测、文字解析隔离、预览确认不覆盖原行程。构建与 TypeScript 检查通过；尚未执行浏览器交互或 PNG 导出视觉测试。

WebMCP: 在支持 document.modelContext 的浏览器注册只读 read_trip_summary。当前环境没有可用的 WebMCP 验证上下文，未声称验证其运行。

## 后续接入

接入真实模型时，在服务端保管密钥；模型输出通过结构化校验，并保留 lib/journey.ts 的约束检查。继续补充真实路线/营业信息、票券录入、用户反馈与可靠持久化。不要把演示规则包装成真实模型能力。
